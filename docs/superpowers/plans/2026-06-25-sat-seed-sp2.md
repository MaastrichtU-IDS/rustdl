```rust
let sat_seed = if hyper_sat_seed_enabled() {
    let n_named = internal.vocabulary.num_classes();
    let subs = owl_dl_saturation::saturate(&internal);
    let mut table: Vec<Vec<ClassId>> = vec![Vec::new(); n_named];
    for ci in 0..n_named {
        let c = ClassId::new(u32::try_from(ci).unwrap_or(u32::MAX));
        table[ci] = subs
            .subsumers_of(c)
            .into_iter()
            .filter(|&d| d != c && (d.index() as usize) < n_named)
            .collect();
    }
    Some(table)
} else {
    None
};
```

## Notes for the implementer

- The seed is **sound by construction** (monotone: adding `sub`'s entailed named subsumers can't flip Sat↔Unsat) — but Task 2's corpus oracle is the proof, not this argument (four "sound by construction" claims were corpus-refuted earlier this project).
- Saturation is computed **once** in `build` (shared across all O(n²) pairs) — never per pair. Confirm `build` is called once per ontology (it is — `HyperCache::build` is the per-ontology cache constructor).
- EL/Horn ontologies route to the saturator fast path and never hit the seeded wedge, so the flag is inert there; the gate's non-wine fixtures mainly confirm FP=0 on the SROIQ ones (pizza, sio, ore-*).
