## Operational gotchas re-confirmed this arc (beyond CLAUDE.md)

- **Sweep parallelism:** 6 arms × default rayon (96 threads each) drove load to 470 and
  manufactured TO noise corpus-wide. The working protocol: `RAYON_NUM_THREADS=24`,
  `-P 4` (plus optionally a second tail-end driver at `-P 3` that skips done stems),
  nothing else on the host, serial adjudication of EVERY flagged row — in this arc,
  **100% of flagged losses dissolved serially** (0/2+0/2 ×5 reps, etc.); the two
  wobbly inverse-functional members (`7532`/`9662`) need ≥5 reps per arm.
- **`gh` on g1 is old:** no `gh run list --branch`, no `workflowName` JSON field — use
  `--jq 'select(.headBranch==…)'` and `name`.
- **`/home` on g1 fills:** the 40 GB debug target did it twice this arc. `rm -rf
  target/debug` is the lever; release artifacts are 1.1 GB and pinned copies live in
  `/tmp` anyway.
- **Backticks in `git commit -m "…"` are shell-substituted.** Use `-F <file>`.
- The budget-test binary (`classify_inconsistency_budget`) is host-load-marginal; the
  composite gate runs it `--test-threads=1` first, then the rest of the suite with the
  four wall tests skipped.
