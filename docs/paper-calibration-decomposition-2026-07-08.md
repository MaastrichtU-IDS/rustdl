# Paper calibration decomposition — 2026-07-08

**Purpose:** the user chose "fix calibration first, then decide venue." Per the
advisor, the *fix's* job is to produce the evidence that decides research-vs-Resource.
This is that measurement — the decomposition of the current silent-miss set.

## The C2 hole (restated)

C2 = "calibrated incompleteness": `complete=true ⟹ MISSED=0`, and every miss is a
flagged-undecided pair. The hole: a trust_sat wedge `Sat` on out-of-fragment structure
(complement/disjunction) concludes "not subsumed" **without timing out**, so a true
subsumption is reported as a definite non-edge — a *silent* miss, not flagged. (Also:
candidate-generation / label-prune misses like 15167 are never tested at all.)

## Decomposition method (current main, OutOfFragment ORE-2015 pilot subset)

For each current silent-miss pair, `explain` (the full engine cascade, 30 s cap) gives
the engine attribution:
- **tableau** — closure (saturation+wedge) returned `Sat`; only the full tableau
  adjudicates. These are trust_sat-class misses: verifiable *if* budget allows and *if*
  classify generated the candidate.
- **DNF** — the tableau itself does not finish in 30 s (wine-class disjunction wall).
  Unverifiable per-pair in any practical budget.
- **saturation/hyper** — the closure *derives* it (a rendering/emission gap, fixable to
  a certain edge, not a calibration-uncertain pair).

## Result (34 sampled pairs across 13 silent-miss onts)

| engine | count (of 34 sampled) | meaning |
|---|---:|---|
| **DNF (tableau wall)** | 19 | unverifiable per-pair; can only be flagged "budget-exceeded" |
| **tableau** | 15 | trust_sat-class, verifiable per-pair |
| saturation/hyper | 0 | no closure-derived-but-unemitted in this sample |

**By pair-sample it is 56% DNF; by MISS COUNT it is ~70%+ DNF** — the DNF pairs
concentrate in the high-count onts (`778`=59, `9786`=55, `12698`=11 → **all DNF**,
≈125 of the ~185 total silent misses), while every tableau-adjudicable pair is in a
low-count ont (`12141`, `13077`, `16847`, `9024`, `12253`, `16461` — 1–2 misses each)
or in `15167` (whose tableau-yes pairs were separately shown to be *candidate-generation*
/ label-prune misses — never generated by the main walk; recovered only by the opt-in
defined-sweep, not by trust_sat=0).

## What this means for the fix, and the venue

Per the advisor's decision rule:

- **A tight, sound uncertain set is INFEASIBLE.** The dominant misses (DNF) cannot be
  verified in any practical budget, so verify-under-budget can only flag them
  "budget-exceeded" → a *huge* uncertain set (most non-edges of the hard onts), not a
  tight one. The remaining adjudicable misses (`15167`) were never generated as
  candidates, so they can't be flagged without full O(n²).
- **The only sound C2 fix that holds is the coarse fragment-gate:** report
  `complete=true` **iff** the fragment is provably complete (PureEl / Horn); OutOfFragment
  ⟹ `complete=false` ("hierarchy not guaranteed complete"). This makes C2 true by
  construction — but it is the trivial "we know our fragment" contract, not a research
  contribution.
- **The anytime-certification revival (verify-under-budget shrinking a tight uncertain
  set) is not supported** — the wall the certification would run into is the same
  wine-class tableau wall, on exactly the onts that carry the misses.

**Verdict: Resource / In-Use track.** The tight-C2 / anytime research thesis is
empirically unsupported. Ship the coarse fragment-gate as an honest soundness fix (no
more false `complete` on OutOfFragment silent misses), and frame the paper on the strong,
built material: soundness (FP=0), the explanation/debugging suite (justify/diagnose/
repair/report/prove — no Konclude equivalent), embeddability, EL/Horn competitiveness,
with calibrated incompleteness as a *characterized property* (fragment-gated guarantee),
not an over-claimed per-pair contract.
