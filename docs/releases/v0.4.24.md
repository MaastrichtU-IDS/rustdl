# v0.4.24 — two soundness fixes, a completeness fix, and the first negative-certificate verifier

`classify` answers change on this release. Nothing regressed: over the full 1,920-ontology
ORE corpus, **no ontology's output changed** except where a fix recovered entailments, and
the corpus-scale MISSED net **fell 2.32%** against a Konclude ∪ HermiT oracle with **FP = 0**.

## The fixes that change answers

**`≤n` merge-pair choice was deterministic — a real false positive (#76, #77).**
The SROIQ `≤`-rule is don't-know nondeterministic over *which* pair to merge, but `apply_max`
took the first non-distinct pair and never reconsidered. When that choice clashed, the whole
branch died and a satisfiable concept was reported unsatisfiable — i.e. a spurious subsumption.
Reproduced on **pizza** (`Margherita ⊑ InterestingPizza`). Each candidate merge is now tried
behind a checkpoint and rolled back if it clashes immediately.

**A naming clause was unanchored, so the wedge returned `Sat` on a subsumed pair (#78, #83).**
`head_atom_for`'s `Not` arm emitted the fresh-`Q` naming clause on `var`, the successor
variable, when the clause states a *universal* property of `Q` (`∀z. ¬(Q(z) ∧ A(z))`). On
`var` the clause carried no `X` atom and no `Role` atom, so it was unmatchable and never
fired — a one-line fix, `var` → `X`. **This closes #66**, where `classify` omitted a
subsumption its own `subclass` query proved. Verified on that issue's minimal reproducer.

**`∃R.{a}` antecedents now absorb (#70, #71).** A two-axiom ontology
(`EquivalentClasses(Q, ObjectHasValue(p, b))` plus one property assertion) ran for hours: the
`⊒` half left a residual whose `Q` disjunct is *generating*, and `is_blocked_anywhere` refuses
to block a nominal node, so nothing ever blocked — 0 blocks in 127,708 calls.

**`rdf:langString` values reached the reasoner for the first time (#72, #75).** They were
dropped at conversion, so a language-tagged value was unconfirmable by any route. The DKey is
now keyed on the **pair** (lexical form, language tag) in its own bucket — sharing `str:`
would let `"bonjour"` and `"bonjour"@fr` subsume one another, the same defect shape as the
v0.4.6–v0.4.9 float/double FP. Also fixed: `inferred_data_property_values` dropped `lang`
*then* deduped, **losing whole assertions**, not just tags.

**Nested existential / min RHS bodies get a two-way marker (#80, #82).**

**`ObjectPropertyRange` now folds into nested existential witnesses (#81).** Two lowering
sites dropped the role's range: the conjunctive-LHS arm called a body helper that takes no
extras, and the inner nested body never received `effective_ranges` at all — so
`∃u.W` under `Range(u,G)` built a witness carrying `W` but not `G`, and any downstream
`W ⊓ G` trigger never fired. Reproducer A returned **zero rows with `incomplete: false`** —
the D10 shape. Unflagged, because given `Range(R)` the classes `∃R.B` and `∃R.(B ⊓ Range(R))`
are the same class, so the fold is a logical identity. Its own two-arm 1,920-ontology sweep:
**0 regressions, 0 answer changes**, 1777 of 1778 both-completed ontologies strictly
answer-identical, both flagged rows adjudicated clean.

### Two measurement traps this release walked into, both caught

**A cross-host baseline made a good build report FAIL.** The gate's `lost_ontologies` clause
asks whether an ontology finished inside the cap — a property of the *machine* as much as the
binary. Against a baseline from faster hardware it reported 2 lost. Re-measuring the **same
v0.4.23 binary** on the candidate's host moved the median **0.21 s → 0.53 s (2.5×, across all
424)**; host-matched, the gate PASSES and the candidate classifies one *more*. The corpus
report now records host provenance and warns on cross-host comparisons.

**A 6-way-parallel sweep manufactured 3 `ok → dnf`.** Re-run sequentially on an idle host with
alternating arm order, 3 runs each, `ore_ont_8429` / `ore_ont_9429` / `ore_ont_9674` all
complete in **both** arms with identical row counts (998 / 2,706 / 981,144) and walls within
noise. Adjudicate a reported loss before believing it.
