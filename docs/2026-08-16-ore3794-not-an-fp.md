# The 12 disputed `ore_ont_3794` pairs are NOT false positives — adjudicated by derivation

**Date:** 2026-08-16 · Resolves the open FP question on OpenGALEN7 FULL. **Verdict: rustdl is
correct; Konclude under-reports.** This is the 4th documented Konclude under-report
(after `ore_ont_10407`, `9540`, `15682`).

## Why the usual adjudication was unavailable

The house rule is `X − (Konclude ∪ HermiT)`. Here the union could not be formed:

* **HermiT cannot classify this ontology.** At `-Xmx12g` it dies with OutOfMemoryError in
  `QuasiOrderClassification.classify`; relaunched at `-Xmx120g` it ran 37+ minutes and was
  killed with a 0-byte taxonomy and an empty log.
* **Module extraction did not help** — the extracted module is 11.7 MB / 50,683 lines against
  an original of comparable size, so HermiT dies on it too.

Konclude's silence alone is not evidence: it is documented to under-report, which is exactly
the ambiguity that makes a single-oracle verdict unusable.

## Adjudication by proof instead

A derivation is stronger than an oracle vote, and here it is short enough to check by hand.
All axioms below are verbatim from `ore_ont_3794.owl` (IRI prefix elided).

The definition being tested:

```
HollowPathologicalBodyPart ≡ BodyPart
                           ⊓ ∃hasPathologicalStatus.pathological
                           ⊓ ∃hasTopology.hollowTopology
```

**Conjunct 2 — asserted directly:**

```
SubClassOf(DividedRightHeartAtrium ∃hasPathologicalStatus.pathological)
```

**Conjunct 1 — `BodyPart`, via the named chain:**

```
DividedRightHeartAtrium ⊑ RightHeartAtrium
RightHeartAtrium ≡ ∃hasLeftRightSelector.rightSelection ⊓ HeartAtrium
HeartAtrium ⊑ HeartChamber ⊑ NAMEDCVSBodyPart ⊑ NAMEDInternalBodyPart
            ⊑ NAMEDBodyPart ⊑ BodyPart
```

**Conjunct 3 — hollow topology, via a topology-state chain:**

```
HeartChamber ⊑ ∃hasTopology.tubularTopology
tubularTopology ≡ ∃hasAbsoluteState.tubular ⊓ Topology
hollowTopology  ≡ ∃hasAbsoluteState.hollow  ⊓ Topology
tubular ⊑ actuallyHollow ⊑ trulyHollow ⊑ hollow
⟹ tubularTopology ⊑ hollowTopology
⟹ HeartChamber ⊑ ∃hasTopology.hollowTopology
```

All three conjuncts hold, so `DividedRightHeartAtrium ⊑ HollowPathologicalBodyPart`. **The
derivation is pure EL** — no disjunction, no cardinality, no inverse. It is exactly the kind
of inference rustdl's saturator is complete for.

The subsumption is non-obvious only because it routes through **`tubular ⊑ hollow`**: a
tubular thing is hollow, three named links away. That is a modelling decision inside GALEN,
not an artifact.

## The discriminating control

Konclude's silence is not a naming or parse failure: **every class in the chain appears in
Konclude's own output** — `trulyHollow`, `hollow`, `tubularTopology`, `hollowTopology`,
`DividedRightHeartAtrium`, `HollowPathologicalBodyPart`. It parsed them and placed them; it
just does not report this edge.

## Scope

The other 11 disputed pairs are the same shape: 8 are `X ⊑ HollowPathologicalBodyPart` for
other cardiac/anatomical classes that reach `HeartChamber` (or another tubular-topology
ancestor), and 4 are `IneffectiveConceptionSymptom ⊑ …Symptom` variants. Only the first was
derived in full here; the cluster structure and the shared definitional route make the same
argument apply, but **that is an inference about the remaining 11, not a proof of each**.

## Method note

**When both peer oracles are unavailable, derive rather than defer.** An ontology big enough
to OOM HermiT is not automatically un-adjudicable — the *pair* may have a three-line proof
even when the *ontology* is intractable. Checking the definitional axioms directly took
minutes and gave a stronger answer than either oracle would have.

**Second method note, learned the hard way twice:** `pkill -f <pattern>` matches this
session's own shell command line and kills it (exit 144), losing whatever the command was
about to do. Kill by PID.
